# InfiNote

**InfiNote**（Infinite + Note）是一個在瀏覽器裡用的無限畫布 PDF 筆記 App。
PDF 頁面、圖片、文字框和便條都擺在同一張白板上。你可以在 PDF 上畫螢光筆，用連結線把筆記接到原文的某段文字，也能一次搜尋所有內容。

> 🔗 線上版：`https://<你的帳號>.github.io/<repo>/`

整個專案只有一個 `index.html`，HTML、CSS、JavaScript 都寫在裡面，不需要後端，也不需要建置工具。

---

## 使用情境

1. 匯入幾份論文 PDF。
2. 把相關的頁面拖到一起。
3. 用螢光筆畫重點。
4. 寫便條，並拉線到對應的文字。
5. 日後用搜尋找回關鍵字。

## 功能

> **文字模式**：縮放 ≥ 75% 時會啟用 PDF 文字層。螢光筆和連結線都只能在文字模式下使用。

| 功能 | 操作方式 | 說明 |
| --- | --- | --- |
| 無限畫布 | 拖曳空白處、按住 `Space` 拖曳或用滑鼠中鍵平移；滾輪、觸控板捏合或 `Ctrl` + 滾輪縮放 | 縮放範圍 10%–400%，以游標為中心；點狀網格可以開關；手機支援雙指縮放 |
| 匯入 PDF | 按工具列的匯入按鈕，或把檔案拖進畫面 | 每頁一張卡片，橫向排成一列；卡片上方顯示「檔名 · p.頁碼」；沒有文字層的 PDF 會提示無法搜尋 |
| 圖片 | 用 `Ctrl/Cmd + V` 貼上，或把圖檔拖進畫面 | 放在游標位置；右下角可等比例縮放 |
| 文字框 | 選「T」後拖曳決定大小，或點一下用預設大小 | 貼上純文字時也會自動建成文字框 |
| 便條 | 選「便條」後拖曳決定大小，或點一下用預設大小 | 便條就是有背景色的文字框，行為完全相同；有 4 種顏色 |
| 螢光筆 | 在文字模式下選「螢光筆」，拖選 PDF 上的文字 | 黃色半透明；縮小或移動頁面後仍在原位；點選後可刪除 |
| 連結線 | 從文字框或便條四邊中央的圓點，拖到 PDF 文字上 | 詳見下方〈連結線規則〉 |
| 物件操作 | 點選、拖曳、按 `Delete` 刪除；雙擊 PDF 頁或圖片會縮放到該物件 | 可復原和重做，最多 60 步 |
| 全域搜尋 | `Ctrl/Cmd + F` 或右上角的搜尋框 | 同時搜尋 PDF 文字、文字框和便條；點選結果會跳過去並標示命中位置 |
| 儲存與備份 | 自動儲存；從「⋯」選單匯出或匯入備份 | 內容存在瀏覽器的 IndexedDB；備份是一個 `.json` 檔 |

### 文字框與便條

| 項目 | 規則 |
| --- | --- |
| 建立 | 按住拖曳，拖出的矩形就是大小；直接點一下則用預設大小（文字框 240×40、便條 200×200） |
| 編輯 | 建立後直接打字；之後單擊只會選取，在框內雙擊或按 `Enter` 才開始編輯；點框外或按 `Esc` 結束編輯 |
| 空白 | 沒有文字也不會消失，會顯示「輸入文字…」 |
| 換行 | 文字依框寬自動換行，超出框的部分直接顯示在框外，不會被截斷 |
| 左上角 ✕ | 點一下刪除整個框 |
| 其餘三個角 | 拖曳調整大小 |
| 四邊中央 | 藍色連結點，從這裡拉出連結線 |

### 連結線規則

1. **起點**：可以從四個邊中央的任一個連結點拖出，線會從那一邊出發。
2. **建立條件**：只能在文字模式（縮放 ≥ 75%）下建立。
3. **終點**：一律接在 PDF 文字上。放在螢光筆上會連到整段螢光筆文字，放在一般文字上會連到那一行。放在空白處不會建立連結。
4. **縮小後**：縮放低於 75% 時，線會在視覺上改接到頁面邊緣；放大回去後，再接回原本的文字。
5. **跳轉**：點筆記這一端的圓點，會跳到連結的文字；點文字那一端的圓點，會跳回筆記。
6. **刪除**：點選線條後按 `Delete`。刪除任一端的物件時，連在上面的線也會一起刪除。

## 快捷鍵

| 按鍵 | 動作 |
| --- | --- |
| `V` / `T` / `N` / `H` / `L` | 切換到選取、文字框、便條、螢光筆、連結線工具 |
| 按住 `Space` 拖曳 | 平移畫布 |
| `Enter` | 編輯已選取的文字框或便條 |
| `Esc` | 結束編輯；取消選取 |
| `Delete` / `Backspace` | 刪除選取的項目 |
| `Ctrl/Cmd + Z` | 復原 |
| `Ctrl/Cmd + Shift + Z`、`Ctrl + Y` | 重做 |
| `Ctrl/Cmd + V` | 貼上圖片或純文字 |
| `Ctrl/Cmd + F` | 搜尋；`Enter` 跳下一筆、`Shift + Enter` 跳上一筆 |

## 部署到 GitHub Pages

```bash
git init
git add index.html README.md
git commit -m "InfiNote"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<repo>.git
git push -u origin main
```

接著到 repo 的 **Settings → Pages**，Source 選 `main` branch 的 `/ (root)`，按 Save。大約 1 分鐘後網站就會上線。

要在本機開發時，直接用瀏覽器開啟 `index.html` 即可；或用 `python3 -m http.server` 開一個本機伺服器。

## 技術架構

- **純前端單檔**：只有 [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174 從 cdnjs 載入，其餘都寫在 `index.html` 裡。
- **畫布**：外層 `div` 用 CSS `transform: translate() scale()` 做平移縮放，物件是絕對定位的 `div`，連結線畫在同一層的 SVG 上。
- **資料驅動**：所有內容都放在 `State.doc`，修改一律透過 `dispatch(action)`，再由 `render()` 依資料重畫畫面。

| 模組 | 負責 |
| --- | --- |
| `CONFIG` | 所有常數：文字模式門檻、縮放範圍、預設大小、顏色 |
| `Store` | IndexedDB 讀寫 |
| `State` | 唯一的資料來源；`dispatch` 負責修改資料、記錄復原、觸發儲存和重繪 |
| `View` | 平移縮放、螢幕座標與畫布座標的轉換、平滑跳轉 |
| `PdfService` | 包裝 PDF.js；只渲染畫面內的頁面；只在文字模式下建立文字層 |
| `ItemTypes` | 每種物件一個 renderer；`note` 和 `textbox` 共用同一個 |
| `Highlights` | 把選取的文字轉成比例矩形，畫在頁面上 |
| `Links` | 計算並畫出連結線（起點在邊中央，終點在文字或頁面邊緣） |
| `Tools` | 把指標事件轉成動作：建立、移動、縮放、拉線、編輯 |
| `Search` | 查詢文字索引和筆記，跳轉並標示命中位置 |
| `UI` | 工具列、情境列、搜尋、縮放、選單、快捷鍵 |

### 資料儲存（IndexedDB）

| Store | 內容 |
| --- | --- |
| `files` | 原始 PDF 和圖片的 Blob，每個檔案只存一次 |
| `items` | 畫布物件：`pdfPage`、`image`、`note`、`textbox`，包含位置和大小 |
| `highlights` | 螢光筆；矩形存成相對頁面的 0–1 比例座標 |
| `links` | 連結線：`fromId`、`fromSide`、`toId`、文字錨點 `anchor` |
| `textIndex` | 匯入時抽出的每頁文字，供搜尋使用 |
| `meta` | 畫布狀態（平移、縮放、網格） |

PDF 頁面不存成圖片，而是存原始檔，每次開啟時重新渲染。這樣佔用空間比較小，放大時也能用高解析度重畫。

## 已知限制

- **資料只存在目前這個瀏覽器**：換電腦或換瀏覽器前，請先從「⋯」選單匯出備份。
- **掃描版 PDF 沒有文字層**：這類 PDF 無法搜尋、畫螢光筆或連結到文字。
- **需要連網**：開啟時要能連上網路，才能從 cdnjs 載入 PDF.js。
- **手機功能有限**：手機可以瀏覽和做基本操作，精細的編輯建議用電腦。
